# CSS - WebDev

A collection of CSS examples, styling exercises, and frontend practice code.

## About

This repository documents my early exploration of web styling, from writing traditional CSS to experimenting with a utility-first CSS framework. It contains learning examples and practice code created while following tutorials and exploring different approaches to styling web pages.

## Topics Covered

- **CSS Fundamentals** — selectors, properties, values, and syntax
- **Colors and Typography** — text styling, fonts, and color schemes
- **Box Model** — margins, padding, borders, and element dimensions
- **Layout and Positioning** — element positioning and page layout techniques
- **Display and Visibility** — controlling how elements are rendered
- **Flexbox and Grid** — CSS layout systems
- **Responsive Design** — adapting layouts to different screen sizes
- **Transitions and Animations** — adding visual effects and motion
- **Tailwind CSS** — utility classes for styling HTML elements
- **Utility-First Styling** — composing layouts and styles using reusable utility classes

*The topics listed are general areas associated with CSS and Tailwind CSS learning; the exact coverage depends on the examples in the repository.*

## Getting Started

### Prerequisites

- A modern web browser.
- A code editor such as Visual Studio Code.
- Basic familiarity with HTML.
- Node.js and npm may be required for examples that use a locally installed Tailwind CSS toolchain.

### Clone the Repository

```bash
git clone https://github.com/naba93980/css.git
cd css
```

### Explore the Examples

1. Browse the repository for the CSS or Tailwind CSS example you want to explore.
2. Open the relevant HTML and CSS files in your editor.
3. Open the associated HTML file in a browser to view the result, if one is provided.
4. For Tailwind CSS examples, follow any project-specific setup instructions if a build process is required.

This repository preserves my early learning journey with CSS and Tailwind CSS, serving as a reference for the styling concepts and techniques I explored while learning frontend web development.
